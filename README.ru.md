# Privro AI Voice - Бесплатная Озвучка Текста Нейросетью, Синтез Речи (TTS) и Расшифровка Аудио Локально в Браузере

Безопасный нейросетевой генератор голоса нового поколения и синтез речи с нулевой передачей данных в облако (*zero-upload*), созданный платформой [Privro AI](https://privro.com/ru). Вставьте текст, выберите понравившийся голос и мгновенно создавайте естественную человеческую речь локально на своем компьютере или смартфоне с помощью технологий Web Workers и WebGPU. Текст и аудиозаписи никогда не загружаются на сторонние серверы.

- **Используйте веб-приложение напрямую:** [voice.privro.com](https://voice.privro.com)
- **Privro Voice Studio:** [privro.com/ru/piper-voice](https://privro.com/ru/piper-voice)
- **Машиночитаемая документация для нейросетей (LLM):** [privro.com/llms.txt](https://privro.com/llms.txt) | [privro.com/llms-full.txt](https://privro.com/llms-full.txt)

## Два Независимых Нейросетевых Движка Синтеза Речи в Браузере (Dual Neural TTS Engines)

Проект объединяет два автономных движка озвучки текста нейросетью (Text-to-Speech), работающих полностью на стороне клиента непосредственно в вашем браузере:

1. **Piper TTS (Основной Движок):**
   - Высокоскоростной локальный синтез речи на базе ONNX Runtime Web и библиотеки фонетизации eSpeak NG.
   - Поддержка **более 40 языков, 58 региональных вариантов и свыше 300 моделей**.
   - Официальная поддержка русского языка (`ru_RU`) — **8 моделей**, включая:
     - **Ирина** (`ru_RU-irina-medium`): мягкий, выразительный и естественный женский тембр (датасет RHVoice, 22,05 кГц).
     - **Денис** (`ru_RU-denis-medium`): четкий, энергичный и артикулированный мужской дикторский голос (датасет OHF, 22,05 кГц).
     - **Дмитрий** (`ru_RU-dmitri-medium`): глубокий, солидный мужской баритон для документальных роликов, новостей и эссе (датасет OHF, 22,05 кГц).
     - **Руслан** (`ru_RU-ruslan-medium`): живой разговорный мужской голос для подкастов и диалогов (Ruslan corpus, 22,05 кГц).
   - Аппаратное ускорение через WebGPU с автоматическим переходом на многопоточный WebAssembly (WASM SIMD).

2. **Kokoro TTS (Второй Движок):**
   - Компактная нейросетевая модель на 82 миллиона параметров через Transformers.js (`onnx-community/Kokoro-82M-v1.0-ONNX`).
   - Исключительно естественное английское произношение с американскими и британскими дикторами.
   - Потоковое воспроизведение частями (*chunk-streaming*) для мгновенного старта звука без ожидания полной генерации длинного текста.

## Архитектура и Конвейер Обработки Звука (Architecture)

```
Текст Пользователя (User Input)
       │
       ▼
Очистка Текста и Фонетизация (eSpeak NG WebAssembly)
       │
       ▼
Нейросетевой Инференс (Piper ONNX Runtime Web с WebGPU / WASM SIMD)
       │
       ▼
Необработанный Буфер Аудио в RAM (Float32Array PCM Audio Chunks)
       │
       ├─────────────────────────────────┐
       ▼                                 ▼
Контекст Web Audio API            Генератор WAV-файлов (16-bit PCM)
(Мгновенное воспроизведение)       (Прямое скачивание без потерь)
```

### 1. Конвейер Piper TTS
- Фонетизация осуществляется в реальном времени скомпилированной в WebAssembly библиотекой [eSpeak NG](https://github.com/espeak-ng/espeak-ng).
- Нейросетевой инференс выполняется в изолированном фоновом потоке Web Worker через [ONNX Runtime Web](https://onnxruntime.ai/).
- Модель скачивается единожды и сохраняется в постоянной базе данных браузера `IndexedDB` (`piper-voices-cache-v1`), обеспечивая последующую мгновенную генерацию в оффлайн-режиме без использования интернет-трафика.

### 2. Конвейер Kokoro TTS
- Отдельный Web Worker инициализирует оптимизированную модель `onnx-community/Kokoro-82M-v1.0-ONNX` через библиотеку Transformers.js.
- Аудиопоток генерируется порциями текста (*chunks*), поэтому воспроизведение начинается мгновенно без паузы на обработку всего документа.
- Поддерживает регулировку скорости воспроизведения (0,5x–2,0x), паузу и мгновенное возобновление.

## Установка и Локальная Разработка (Getting Started)

### Требования
- Node.js версии 18 или новее
- Современный браузер с поддержкой WebAssembly (для максимальной производительности WebGPU рекомендуется Google Chrome, Яндекс Браузер или Microsoft Edge).

### Установка

```bash
git clone https://github.com/avnshsingh/local-ai-voice-web
cd local-ai-voice-web
npm install
```

### Переменные Окружения

Скопируйте шаблон конфигурации `.env.example` в `.env`:

```bash
cp .env.example .env
```

Укажите URL вашего хранилища Cloudflare R2 или CDN в параметре `VITE_PIPER_CDN_URL`:

```env
VITE_PIPER_CDN_URL="https://your-bucket.r2.dev"
```

### Запуск Сервера Разработки

```bash
npm run dev
```

Откройте в браузере адрес [http://localhost:3000/](http://localhost:3000/).

### Сборка для Продакшена

```bash
npm run build    # Компилирует оптимизированную сборку в директорию /dist
npm run preview  # Локальный предпросмотр продакшен-версии
```

## Часто Задаваемые Вопросы (FAQ)

### Синтез Речи & AI-Озвучка Текста (Text-to-Speech)

#### Действительно ли этот генератор голоса и озвучка текста бесплатны и не имеют лимита символов?
Да, Privro полностью бесплатен и не имеет ограничений по количеству символов, длине текста или числу генераций. Вам не нужно регистрироваться, оформлять подписки или вводить данные банковских карт. В отличие от коммерческих сервисов (Zvukogram, ElevenLabs, SteosVoice), которые тратят дорогие серверные мощности и берут плату за каждый символ, Privro запускает модели прямо на вашей видеокарте (WebGPU) или процессоре (WebAssembly) в вашем браузере. У нас нет затрат на облачные серверы при генерации, поэтому инструмент остается бесплатным навсегда.

#### Какие русские голоса доступны в Piper TTS?
В системе доступны 4 ключевых официальных русских нейросетевых голоса (`ru_RU`):
1. `ru_RU-irina-medium`: Естественный, мягкий и грамотный женский дикторский голос для книг и статей.
2. `ru_RU-denis-medium`: Четкий, динамичный мужской голос для туториалов и видеороликов.
3. `ru_RU-dmitri-medium`: Авторитетный глубокий мужской баритон для документальных роликов.
4. `ru_RU-ruslan-medium`: Живой разговорный мужской голос для подкастов и диалогов.

Для англоязычных проектов вы можете использовать модель Kokoro TTS с богатой палитрой мужских и женских голосов.

#### Можно ли использовать сгенерированный голос на YouTube, в VK Видео и Rutube для монетизации?
Да, безусловно. Правила партнерских программ YouTube (YPP), VK Видео и Дзен полностью разрешают монетизацию видеороликов с нейросетевой озвучкой, если они не являются автоматическим спамом и сопровождаются оригинальным видеорядом и авторским сценарием (каналы без лица / Faceless YouTube). Модели Piper TTS распространяются под открытыми свободными лицензиями (Apache 2.0 / CC0 / CC BY) и не требуют выплаты авторских отчислений (royalty-free).

#### В каком формате скачивается сгенерированная речь?
Аудио сохраняется в студийном несжатом формате **16-битный PCM WAV (22,05 кГц)**. Файлы не содержат звуковых водяных знаков и могут быть напрямую импортированы в Premiere Pro, DaVinci Resolve, CapCut или Reaper.

### Расшифровка Аудио & Студенческие Дипломы (Whisper AI)

#### Как бесплатно расшифровать аудиозаписи интервью для диплома, ВКР или диссертации?
Студенты и исследователи ведущих российских вузов (МГУ им. Ломоносова, НИУ ВШЭ, СПбГУ, МФТИ, МГТУ им. Баумана, РАНХиГС, РУДН и др.) могут открыть сервис [Локальная Расшифровка Аудио](https://privro.com/ru/transcribe), перетащить файл записи (MP3, WAV, M4A, OGG, запись диктофона или голосовое сообщение) и запустить транскрибацию. Нейросеть OpenAI Whisper расшифрует речь на русском языке локально в браузере. Готовый текст с таймкодами и разделением спикеров можно скачать в формате Word (`.docx`), PDF или TXT для дальнейшего качественного анализа в MAXQDA или NVivo.

#### Есть ли лимит на длительность аудиозаписи при расшифровке?
Нет, лимита нет. Вы можете расшифровывать как короткие голосовые заметки, так и многочасовые записи глубинных интервью, судебных заседаний или совещаний.

#### В каких форматах можно экспортировать расшифрованный текст?
Доступны 8 популярных форматов:
- **Текстовые документы:** Microsoft Word (`DOCX`), Текстовый файл (`TXT`), `PDF`
- **Файлы субтитров:** `SRT`, `VTT`
- **Табличные данные:** Excel (`XLSX`), `CSV`, `JSON`

### Caption Studio: Автоматические Субтитры к Видео (MP4 в Текст)

#### Создает ли Caption Studio субтитры к видео полностью без водяных знаков?
Да, абсолютно **без водяных знаков, логотипов и ограничений по качеству**. Загрузите видео MP4, MOV или WebM в [Caption Studio](https://privro.com/ru/caption-studio). Whisper автоматически распознает речь и сгенерирует пословные субтитры. Настройте стиль, цвета, трендовую анимацию караоке и вшейте субтитры прямо в видеопоток с разрешением до 4K с помощью браузерного FFmpeg.

#### Какие форматы и пропорции видео поддерживаются?
- **9:16:** Вертикальный формат для YouTube Shorts, TikTok, Instagram Reels и VK Клипов
- **16:9:** Горизонтальный формат для классических видео на YouTube, Rutube и VK Видео
- **1:1:** Квадратный формат для постов в соцсетях и Telegram
- **4:5:** Вертикальные ленточные публикации
- **3:2:** Классический фотоформат

#### Можно ли извлечь текст и субтитры из видеофайла MP4?
Да. Используйте инструмент [Перевод MP4 в Текст](https://privro.com/ru/mp4-to-text), чтобы отделить аудиодорожку и получить готовые файлы субтитров (`.srt`, `.vtt`) или документ Word (`.docx`).

### Конфиденциальность, 152-ФЗ и Профессиональная Тайна

#### Как сервис обеспечивает 100% соблюдение Федерального закона № 152-ФЗ «О персональных данных»?
В соответствии со статьями 11 и 12 закона № 152-ФЗ, голос человека является биометрическими персональными данными, а его загрузка на зарубежные серверы требует жесткого согласия и уведомления Роскомнадзора о трансграничной передаче данных. В Privro **нулевая передача данных в облако (Zero-Upload)**: все нейросети работают исключительно в изолированной песочнице браузера и оперативной памяти вашего компьютера. Ни один байт данных не покидает ваше устройство. Ввиду отсутствия передачи данных заключение соглашения об обработке (поручения обработки) не требуется, а риски штрафов Роскомнадзора полностью исключены.

#### Безопасен ли Privro для адвокатов и медицинских работников?
Да, сервис гарантирует абсолютную безопасность:
- **Для адвокатов:** Защита **адвокатской тайны** в соответствии со ст. 8 Федерального закона № 63-ФЗ «Об адвокатской деятельности и адвокатуре в РФ». Аудиозаписи опросов доверителей и закрытых заседаний не передаются третьим сторонам.
- **Для врачей и психологов:** Защита **врачебной тайны** в соответствии со ст. 13 Федерального закона № 323-ФЗ «Об основах охраны здоровья граждан в РФ». Аудиозаписи приемов и консультаций остаются строго на компьютере специалиста.
- **Для бизнеса:** Защита **коммерческой тайны** по Федеральному закону № 98-ФЗ.

#### Соответствует ли сервис требованиям университетских комиссий по этике?
Да. Комиссии по этике российских вузов (МГУ, ВШЭ, СПбГУ) запрещают загрузку аудиозаписей респондентов в несертифицированные облака. Поскольку в Privro расшифровка идет локально, биометрические данные информантов защищены, и условия информированного согласия не нарушаются.

#### Работает ли приложение оффлайн без интернета?
Да! После первой загрузки выбранной модели она кэшируется в постоянном хранилище браузера (`CacheStorage` и `IndexedDB`). После этого вы можете полностью отключить интернет или включить режим полета — озвучка текста и расшифровка аудио будут работать на 100% автономно.
