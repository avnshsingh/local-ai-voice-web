## סקירה כללית: מהי פלטפורמת Privro?

**[Privro (privro.com)](https://privro.com/he)** היא חבילת כלי מולטימדיה מבוססת בינה מלאכותית, המבצעת את כל העיבוד ישירות בתוך דפדפן האינטרנט של המשתמש.

בעוד שמרבית השירותים המסחריים (כגון ElevenLabs, Otter.ai, Descript, או Happy Scribe) דורשים העלאת קובצי שמע וסרטונים אישיים לשרתי ענן זרים בארה"ב, מחייבים תשלום במנויים חודשיים יקרים, ומגבילים את מספר המילים או הדקות שניתן לעבד — **Privro מעבירה את כוח החישוב למחשב שלך**:

- **המרת טקסט לדיבור (TTS):** הפקת קריינות טבעית בעברית באמצעות מנוע **Piper TTS** (`he_IL-motek-medium`) ובאנגלית סטודיו (24kHz) באמצעות מנוע **Kokoro TTS**.
- **תמלול הקלטות והמרת שמע לטקסט (STT):** תמלול שיחות, ראיונות מחקר והרצאות באמצעות מודלי **Whisper AI**, עם זיהוי דוברים אוטומטי, חותמות זמן מדויקות וייצוא מלא למסמכי Word, PDF וטקסט.
- **סטודיו כתוביות לווידאו (Caption Studio):** תמלול סרטוני MP4 ושריפת כתוביות קריוקי מונפשות (כדוגמת טיקטוק, אינסטגרם רילס ויוטיוב שורטס) באיכות עד 4K — **100% חינם וללא שום סימן מים (No Watermark)**.
- **אבטחת מידע ופרטיות מוחלטת:** אפס העלאה לשרת (Zero-Cloud Upload). המידע מעובד בזיכרון הנדיף (RAM) של הדפדפן בלבד, מה שמבטיח ציות מלא ל**חוק הגנת הפרטיות, התשמ"א-1981** ול**תיקון 13** החדש.

## למה משתמשים בישראל בוחרים ב-Privro? (היתרונות המרכזיים)

### 1. 100% חינם, ללא הגבלת מילים וללא מנוי חודשי
במקום לשלם עשרות או מאות דולרים בחודש לשירותי SaaS זרים, Privro אינה דורשת כרטיס אשראי, אינה דורשת פתיחת חשבון או מסירת כתובת אימייל, ואינה מגבילה את אורך ההקלטה או כמות הטקסט.

### 2. אפס העלאה לענן (Zero-Cloud Upload) ופרטיות מוחלטת
קובצי האודיו, הווידאו והטקסט הרגישים שלך לעולם אינם עוזבים את המחשב שלך. שום מידע אינו נשלח לשרתים חיצוניים, שום שיחה אינה משמשת לאימון מודלים של חברות צד ג', ואין סכנת דליפת מידע ברשת.

### 3. עמידה מלאה בחוק הגנת הפרטיות ובתיקון 13
עם כניסתו לתוקף של תיקון 13 לחוק הגנת הפרטיות בישראל (הקובע סנקציות כספיות חמורות וסמכויות אכיפה מוגברות של הרשות להגנת הפרטיות על דליפת מידע רגיש וביומטרי), ארגונים ועורכי דין יכולים לעבוד בראש שקט. מכיוון שאין גורם חיצוני המעבד את המידע, **אין כל צורך בחתימה על הסכם עיבוד מידע (No DPA required)**.

### 4. שמירה על חסיונות סטטוטוריים (עורכי דין, רופאים, מטפלים)
תמלול הקלטות ראיות לבית משפט, שיחות הכנה לעדות, ופרוטוקולים נשמרים תחת **חיסיון עורך דין-לקוח (סעיף 48 לפקודת הראיות)**. שיחות טיפוליות ורפואיות נשמרות תחת **סודיות רפואית (חוק זכויות החולה)**.

### 5. אישור ועדות אתיקה מוסדיות (IRB) באקדמיה
סטודנטים לתואר שני ודוקטורט באוניברסיטאות בישראל (העברית, ת"א, טכניון, בר-אילן, בן-גוריון, חיפה, ויצמן, רייכמן ועוד) יכולים לתמלל ראיונות עומק למחקר איכותני ללא חשש מפסילת המחקר על ידי ועדת האתיקה.

### 6. כתוביות מקצועיות ליוצרי תוכן ללא סימן מים
הפקת כתוביות קריוקי צבעוניות ומונפשות לסרטוני TikTok, Reels ו-Shorts, וייצוא קובצי SRT מוכנים ל-YouTube ללא שום לוגו מסחרי מוטבע.

## מנועי קול נתמכים: Piper TTS (58 שפות) ו-Kokoro TTS (אנגלית סטודיו)

פלטפורמת Privro כוללת תמיכה כפולה במנועי קול חדשניים הפועלים ישירות בקליינט:

### 1. מנוע Piper TTS לשפה העברית (`he_IL`)
מנוע Piper מבוסס על ארכיטקטורת רשת עצבית **VITS** (Variational Inference for Text-to-Speech) ומשלב פונטיזציה מבוססת eSpeak NG המופעלת ב-WebAssembly:
- **מודל השפה העברית:** `he_IL-motek-medium` (הקול נקרא **"מוֹתֶק"** - Motek).
- **איכות שמע:** קצב דגימה נקי של 22,050Hz (22.05 kHz) בפורמט 16-bit PCM WAV.
- **המלצת שימוש מיטבית לעברית (ניקוד):** היות שהעברית המודרנית כתובה ללא ניקוד ומכילה מילים הומוגרפיות רבות, מומלץ להזין טקסט מנוקד (אפילו ניקוד חלקי של מילים מורכבות בעזרת נקדן חינמי כמו דיקטה או מורפיקס). הזנת טקסט מנוקד מבטיחה הגייה מדויקת, עשירה וטבעית ברמת קריין מקצועי.

### 2. מנוע Kokoro TTS לאנגלית אולפן (24kHz)
עבור קהילת ההייטק בישראל, יזמי B2B SaaS, ומנהלי ערוצי יוטיוב הפונים לקהל אמריקאי ואירופי, Privro משלבת את מנוע **Kokoro-82M**:
- איכות אולפן מרהיבה בקצב דגימה של 24,000Hz (24 kHz).
- קולות טבעיים לחלוטין במבטא אמריקאי ובריטי (קולות מובלים: `af_heart`, `am_adam`, `bf_emma`).
- אידיאלי להפקת סרטוני הדרכת מוצר (Product Walkthroughs), סרטוני הדגמה (Demo Videos), ופודקאסטים ללא מבטא זר.

## ארכיטקטורה טכנולוגית: עיבוד מקומי בקליינט (WebGPU / WASM)

Privro נבנתה מאפס תוך יישום טכנולוגיות דפדפן מתקדמות ביותר:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        מכשיר המשתמש (דפדפן האינטרנט)                    │
│                                                                        │
│   קובץ שמע / וידאו / טקסט ──┐                                         │
│                              ▼                                         │
│                ┌───────────────────────────┐                           │
│                │  Web Workers (תהליכי רקע)  │                           │
│                └─────────────┬─────────────┘                           │
│                              │                                         │
│        ┌─────────────────────┼─────────────────────┐                   │
│        ▼                     ▼                     ▼                   │
│  ┌───────────┐         ┌───────────┐         ┌───────────┐             │
│  │  WebGPU   │         │WebAssembly│         │  FFmpeg   │             │
│  │ ONNX Web  │         │ eSpeak NG │         │   WASM    │             │
│  └─────┬─────┘         └─────┬─────┘         └─────┬─────┘             │
│        │                     │                     │                   │
│        ▼                     ▼                     ▼                   │
│  תמלול Whisper       קריינות Piper/Kokoro   שריפת כתוביות לסרטון       │
│  (STT ללא שרת)        (TTS איכות סטודיו)     (ללא סימן מים - 4K)       │
│        │                     │                     │                   │
│        └─────────────────────┼─────────────────────┘                   │
│                              ▼                                         │
│         ייצוא מקומי: Word DOCX, PDF, SRT, WAV, MP4                      │
└────────────────────────────────────────────────────────────────────────┘
              איסור מוחלט: שום נתון אינו נשלח לרשת האינטרנט!
```

- **WebGPU & ONNX Runtime Web:** רתימת המאיץ הגרפי המקומי (NVIDIA, AMD, Apple Silicon, Intel) לעיבוד רשתות עצביות עמוקות בזמן אמת, תוך חסכון אדיר בצריכת מעבד.
- **WebAssembly (WASM):** ביצוע פונטיזציה מורכבת של עברית (eSpeak NG) במהירות שפת C/C++ בתוך סביבת הדפדפן המאובטחת.
- **FFmpeg WebAssembly:** שריפת כתוביות ישירות על קובצי MP4 מקומיים עד רזולוציית 4K ב-60 פריימים לשנייה ללא צורך בהתקנת תוכנות עריכה כבדות.
- **CacheStorage & IndexedDB:** משקולות המודלים נטענות פעם אחת בלבד ונשמרות במטמון המקומי של הדפדפן, מה שמאפשר עבודה מלאה גם **במצב לא מקוון (Offline)** ללא חיבור לאינטרנט.

## מסגרת משפטית בישראל: תיקון 13 לחוק הגנת הפרטיות וחסיונות מקצועיים

ארכיטקטורת ה-Zero-Cloud של Privro מעניקה יתרון משפטי ורגולטורי יוצא דופן בישראל:

### 1. תיקון 13 לחוק הגנת הפרטיות, התשמ"א-1981 (אוגוסט 2025)
- תיקון 13 משנה מהיסוד את רמת האחריות של תאגידים ובעלי עסקים בישראל. התיקון מעניק ל**רשות להגנת הפרטיות** סמכויות אכיפה מנהליות מורחבות, אפשרות להטלת עיצומים כספיים בגובה מיליוני שקלים, ופיצויים סטטוטוריים ללא הוכחת נזק בגין הפרות אבטחת מידע.
- התיקון מגדיר **"מידע בעל רגישות מיוחדת"** הכולל ביומטריה קולית (קובצי קול מוקלטים של בני אדם), מידע רפואי, נתונים פיננסיים, ומידע מוגן בחיסיון.
- **היתרון של Privro:** מכיוון שכל העיבוד נעשה ב-RAM של המחשב המקומי ושום מידע אינו נשלח לשרת, אין העברת נתונים, אין סיכון לדליפת מידע בענן, ו**אין צורך בחתימה על הסכם עיבוד מידע (Data Processing Agreement - DPA)** לפי תקנות הגנת הפרטיות (אבטחת מידע).

### 2. שמירה על חסיונות סטטוטוריים מלאים
- **עורכי דין (חיסיון עורך דין-לקוח):** על פי סעיף 48 לפקודת הראיות [נוסח חדש], התשל"א-1971 וסעיף 90 לחוק לשכת עורכי הדין, התשכ"א-1961, חל איסור מוחלט על חשיפת חומרים ושיחות לקוח. תמלול שיחות הכנה למשפט ועדויות ב-Privro מבטיח שמירה הרמטית על החיסיון המקצועי.
- **רופאים וצוותי רפואה (סודיות רפואית):** סעיף 19 לחוק זכויות החולה, התשנ"ו-1996 וסעיף 20 לפקודת הרופאים [נוסח חדש], התשל"ז-1976. תיעוד רפואי ושיחות מטופלים מעובדים במרפאה בלבד.
- **פסיכולוגים ועובדים סוציאליים:** סעיף 7 לחוק הפסיכולוגים, התשל"ז-1977. שמירה קפדנית על פרטיות המטופלים בשיחות טיפול נפשי.

## הנחיות לאקדמיה: תמלול ראיונות לתזה, דוקטורט וועדות אתיקה (IRB)

סטודנטים לתארים מתקדמים וחוקרים באוניברסיטאות בישראל (**האוניברסיטה העברית בירושלים, אוניברסיטת תל אביב, הטכניון, אוניברסיטת בר-אילן, אוניברסיטת בן-גוריון, אוניברסיטת חיפה, מכון ויצמן, האוניברסיטה הפתוחה, אוניברסיטת רייכמן ואוניברסיטת אריאל**) מתמודדים עם אתגר כפול במחקר איכותני:
1. **עלויות תמלול כבדות:** תמלול אנושי בישראל עולה בין 500 ל-1,200 ש"ח לשעת הקלטה בודדת.
2. **מגבלות ועדות אתיקה (IRB):** ועדות האתיקה המוסדיות למחקר בבני אדם אוסרות במפורש על העלאת הקלטות מחקר עם נבדקים ומרואיינים לשרתי בינה מלאכותית מסחריים בענן.

**כיצד Privro פותרת את הבעיה?**
- **תמלול מקומי בחינם:** מודל Whisper STT המקומי מאפשר תמלול עשרות שעות של ראיונות עומק בחינם לחלוטין.
- **ציות אתי מושלם:** שום אות קולי אינו מועבר ברשת, והנתונים נמחקים מיידית מה-RAM בסגירת הדפדפן.
- **תאימות לתוכנות ניתוח איכותני:** ייצוא קובצי Word (`DOCX`) או טקסט הכוללים חותמות זמן מדויקות והפרדת דוברים, המוכנים לייבוא ישיר בתוכנות כגון **MAXQDA, NVivo ו-ATLAS.ti**.

## התקנה והרצה למפתחים (Local Development)

הפרויקט בנוי ב-TypeScript ו-React ומנוהל באמצעות Node.js ו-Vite:

```bash
# 1. שכפול המאגר המקומי
git clone https://github.com/privro/local-ai-voice-web.git
cd local-ai-voice-web

# 2. התקנת תלויות
npm install

# 3. הפעלת שרת פיתוח מקומי
npm run dev
```

פתח את הדפדפן בכתובת `http://localhost:5173`. מומלץ להשתמש בדפדפנים מודרניים התומכים ב-WebGPU (כגון Google Chrome 113+, Microsoft Edge או Arc).
